# Projects

## Stay Data Stay

![Project image placeholder]({{ '/assets/images/project-placeholder.svg' | relative_url }})

Stay Data Stay is a privacy protection application for travelers. It allows users to record their hotel stay, log the accounts they've accessed on shared devices, and schedule automated logout reminders.

- **Repository:** [kawilson129-cpu/Kiona-629](https://github.com/kawilson129-cpu/Kiona-629)
- **What I contributed:** Entire application design, logic implementation, and user interface development.
- **Tools/technologies:** Python, Git, Jekyll, GitHub Pages.
