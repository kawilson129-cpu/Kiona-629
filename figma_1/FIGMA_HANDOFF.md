# Stay Data Stay · One-file Figma completion

These are implementation instructions, not a record of performed Figma activity.
No connected editor was available; [tool discovery](evidence/tool-availability.json)
records that limitation. Use one Design file for all four assignments.

1. Preserve the original `.jam`. If reviewing historical work, use Figma's file
   browser **Import** to open a copy as FigJam. Do not rename `.jam` or its internal
   `canvas.fig` into a Design submission. [Supported native file imports](https://help.figma.com/hc/en-us/articles/360041003114-Import-files-to-the-file-browser).
2. Create a Figma **Design** draft named `Stay Data Stay / Figma 1`. Follow
   [Assignment 1](assignment_1_frames/README.md) to make a native 1440×960 frame
   and import the supplied SVG. The SVG is preparation, not that native object.
3. Verify the actual PNG image fill and its placement using
   [Assignment 2](assignment_2_images/README.md). The existing portfolio PNG is the
   fallback if an embedded raster does not survive SVG import.
4. Apply/inspect native text and shape properties using
   [Assignment 3](assignment_3_styling/README.md). Recreate outlined labels as Text
   if necessary. Record actual fonts; do not infer them from raster lettering.
5. Convert the [row candidate](assignment_4_components/account-row.svg) to a native
   component and replace the three visual copies with linked instances. Follow
   [Assignment 4](assignment_4_components/README.md) for the propagation check.
6. Save the native `.fig`, actual Design-file/node link and real editor captures
   inside the corresponding assignment folders. Update statuses only after checking
   those artifacts. No placeholder screenshot or invented Figma URL is supplied.

Each assignment names the exact future captures it needs. A screenshot of the
canvas alone cannot prove a frame type, an editable font or an instance relationship.
No interactive prototype, notification delivery or application build is required
by the four supplied criteria, and none is represented as implemented by these assets.
