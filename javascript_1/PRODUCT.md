# DeRexi Priority Practice · coursework scope

The user requested a standalone, dependency-free HTML/CSS/JavaScript calculator
inside the existing JavaScript 1 course, demonstrating eight JavaScript criteria.
Primary users are the student and instructor exploring synthetic policy/incident
scenarios. Success is a working, accessible calculator with actual test evidence.

## Stack and boundaries

Plain static HTML/CSS and exactly one external application JavaScript file,
as explicitly requested. No backend, database, API, production workflow, external
assets, credentials, persistence or real incident assessment. Tests may run with
installed Python, Node and Chrome. Only this course may be edited.

## Established design and decisions

Inherit the canonical DeRexi paper/ink/champagne palette, serif wordmark, hairlines,
semantic forms and textContent/event-listener patterns. The user additionally pins
plum/cranberry accents. Use installed serif/system fonts so the page works offline.
The surface is a task tool: input form paired with a legible assessment panel.
The user delegated routine decisions and explicitly requested autonomous completion;
no design interview or separate visual identity is needed. Scoring thresholds are
new, clearly labelled classroom rules, not copied production incident heuristics.
